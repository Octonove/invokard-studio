# Security

Invokard Studio Local runs on your computer and does not connect to any online service while it works (see "What it
runs, and what it sends" in the README).

## Reporting a vulnerability

Please report security problems privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Include what you ran, what happened and, if you can, a minimal project that reproduces it.
Every report is read and investigated, and a fix or a mitigation is published as soon as it is ready.

Bugs that are not security problems: [GitHub issues](https://github.com/Octonove/invokard-studio-local/issues).
