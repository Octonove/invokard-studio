# Bundled fonts

Open-licensed Google Fonts families (SIL Open Font Licence 1.1, each folder has its `OFL.txt`), latin and latin-ext, every weight the family ships. Renders that use them need no network. Built with `node tools/fetch_fonts.mjs`.

- Inter
- Outfit
- Figtree
- Poppins
- Montserrat
- Space Grotesk
- Barlow
- Barlow Condensed
- Oswald
- Anton
- Bebas Neue
- Playfair Display
- Fraunces
- Shrikhand
- Caveat
