# Simplifica con IA — three prompt reels (30-39 s, Spanish, illustrations + voice)

Three reels for an Instagram account about practical AI prompts: "La foto de los viernes" (a kitchen turned into a
magazine cover), "La nevera de las 21:40" (dinner from an almost empty fridge) and "El retrato que tu perro nunca te
dejó hacer". Each one: a hook, the prompt explained in three rules, a before/after, and a "comment WORD" outro.

| | |
|---|---|
| Route | **A · Generated** |
| Voice | one file per sentence, captions timed word by word |
| Images | Nano Banana Pro; video clips Kling 3.0 at 720p (five clips per reel, ~1,600 credits of video for the three) |
| Engine pieces | `hook`, `section_label`, `chip`, `wipe_scene`, `outro_fan` + `outro_comment` |

These three were produced with the previous (Spanish-API) version of this engine; the components are the same ones
now exported by `pieces.py`. Their scripts predate the port and are not included. Files: the three 720p copies, the
three covers (`cover-*.jpg`) and `preview-nevera.gif`.
